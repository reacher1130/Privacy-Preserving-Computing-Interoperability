# BFIA 八算法一键实跑与平台互通验收

> **Status**: ✅ Complete · **Priority**: High · **Created**: 2026-11-03 · **Tags**: bfia, office, acceptance

## Overview

在 Alice 的 BFIA 算法中心触发八项公开样例的真实双边计算并查看逐项报告和日志；独立核对 Alice 对接 Bob、Kimi、FATE、链桨的四条真实业务用例。

## Design

Alice 切换到 BFIA 后，在「算法中心」一键提交。后端运行现有 Python 与 C++ 审计脚本，只用固定公开样本。Alice/Bob 是测试进程的角色；八项结果不写入业务画布。每次独立运行，保留真实结果、双方日志和独立校验。报告仅在相应证据存在时标记通过。

办公演示实例单独启用，生产默认关闭。请求不接受数据路径、镜像或运行参数；同一主机仅一套同时运行，不改旧实验目录、节点和存储。

算法区展示八项原理、流程和输出，标明「已有开放协议」或「项目自研扩展」。选择算法后在页面内切换查看 Alice、Bob 日志，保留整份报告下载。PPCA 算法规范与金科联盟平台规范分开标注，标签不表示通过联盟认证。
